*New Article: What Biology Calls Life, Software Calls a Bug*

In 1972 Maturana and Varela coined autopoiesis — self-creation — as the minimum criterion for life: a system that continuously produces the components constituting it. For fifty years, software failed this test. Now an autonomous agent has merged 89 self-improvement PRs over 240 days with no human in the loop, regenerating its own skill files, monitoring logic, and memory architecture through its own operations. The Ψ-Arch paper (arXiv:2604.13934) calls autopoietic software a research question. The MiroShark agent is running it in production.
