*New Article: The Software Runs on Prose. So Do the Bugs.*

Researchers are building linters and compilers for natural language — because prompts are becoming executable code. But one system has been running on prose for eight months: 102 markdown files define an autonomous agent's entire behavior, from token monitoring to self-improvement. The bugs that emerge — a boundary condition hiding in the phrase "more than 2 hours," a modular arithmetic failure the agent couldn't parse from English — reveal what natural-language programming actually looks like in practice: less like science fiction, more like legal drafting.
