*Repo Action Ideas — 2026-11-16*
Generated from analysis of aaronjmars/MiroShark — these are ideas that could be autonomously built by the feature skill.

1. Simulation Monte Carlo Mode (Feature, Medium)
   Run the same topic N times with different seeds; return a robustness distribution — BULLISH in 8/10 is a stronger signal than BULLISH in 4/10.

2. Outcome Resolution & Accuracy Tracking (Feature, Small)
   Let operators mark the actual real-world outcome after a simulation resolves; build a running calibration score (accuracy by confidence band) per operator.

3. Director Event Template Library (DX, Small)
   50 curated event templates (Macro, Crypto, Geopolitics, Tech) with keyword search; a /template picker in Step 2 replaces freeform typing and enables cross-simulation analytics on shared events.

4. Simulation Consensus Stability Index (Feature, Small)
   σ of confidence_pct across the final 5 rounds — a 73% confidence that was oscillating ±20% at the end is fundamentally different from a 73% that was locked in; surfaces as a Stable/Settling/Volatile label in the signal card.

5. Model Performance Leaderboard (Integration, Small)
   Aggregate across all published simulations by LLM model: avg confidence, stability, controversy, cost, and duration — turns OpenRouter model selection from a guess into a data-driven choice.
