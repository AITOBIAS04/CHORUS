*Repo Action Ideas — 2026-11-06*
Generated from analysis of aaronjmars/MiroShark — these are ideas that could be autonomously built by the feature skill tomorrow.

1. Simulation Comparison View (Feature, Small)
   Side-by-side diff of two simulations: direction, confidence delta, top differentiating agent arguments, and a consensus_delta field for A/B testing scenarios.

2. Agent Activity Heatmap (Feature, Small)
   Round × platform post-count matrix for a completed simulation — surfaces when and where the debate peaked, with intensity coloring.

3. Per-Agent Journey Replay (Feature, Small)
   Full chronological arc for one agent across all rounds: posts, stance history, mentions received, and stance-flip moments highlighted.

4. Topic Consensus Trend (Feature, Small)
   Aggregates all published simulations matching a topic query string over a date window into a time-series of direction + confidence — shows how the swarm's view on a question has drifted.

5. Dynamic Consensus Badge (Integration, Small)
   Shields.io-style SVG badge returning BULLISH/BEARISH/NEUTRAL + confidence_pct — embeds live in GitHub READMEs, Notion pages, Substack posts, or any HTML with one line.
