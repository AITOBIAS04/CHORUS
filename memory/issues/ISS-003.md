## Summary

Every enabled skill in cron-state.json is failing with the same error signature:

```
api_error_status: 403
api_error_code: oauth_not_all[owed] (truncated in JSON)
is_error: true
num_turns: 1
tokens user: 0, system: 0
```

Zero tokens consumed means Claude Code never authenticated — the API key is rejected before any work begins.

## Remediation

1. Generate a new ANTHROPIC_API_KEY at console.anthropic.com
2. Update the `ANTHROPIC_API_KEY` secret in the GitHub repo settings (Settings → Secrets → Actions)
3. Manually re-run any critical missed skills (token-report, push-recap, repo-pulse) after key renewal
4. Monitor next scheduled run to confirm recovery
